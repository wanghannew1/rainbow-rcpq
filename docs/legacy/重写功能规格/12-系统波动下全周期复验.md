## 除零行为分析

`PRC_计算平均工资` 对无 TC93 工资行的人员:
1. 过程内部捕获 ORA-01476 → 返回 appCode=-1 + errMsg='计算平均工资出错,除数为0'
2. 框架将 -1 转为 LemisBusinessException(有 title) → 不会触发 :83 NPE
3. 用户看到 errMsg 通过 200 响应传回（非 500）

**但本次实际返回 500 而非 200 结构化错误** — 因为 errMsg 中的格式化文本
被框架二次包装时触发 :83 NPE（title 为 null 的 LemisException）。
这是框架层的 UX 缺陷（00 卷形状律 #11），非业务层问题。
