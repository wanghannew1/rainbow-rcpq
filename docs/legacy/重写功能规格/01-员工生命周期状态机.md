## 二、各状态驱动通道

| 起始 | 目标 | 通道 | 前置条件 | 侧效应 |
|---|---|---|---|---|
| 暂存('1') | — | REQ-tdba_cont-save | 三 store 复合(TC90+TB91+TC9E) | TC90 插入+TB91 插入(ATB91Z 回链)+AC01 回写 |
| '1'→提交('2') | REQ-tdba_cont-commit | 仅置 atb90r/atb912 | TB912 同步 '1'→'2' | |
| '2'→通过('3') | PRC_COMFIRM_SH '3' | 需要 TC90_LIST 数据 | TC90_LIST 缺失时仍通过(零外键) | |
| '2'→打回('4') | PRC_员工批量审核不通过 | TB912→'4' | TC90 不变 | |
| '3'→终止送审('2') | PRC_变更参保地 或 PRC_员工终止审核_批量 | AAE100→'0'+镜像列 | 死亡行仍可终止(零外键) | |
| 终止送审('2')→终止生效('5') | PRC_员工终止审核_批量 | TC93.ATC93V='5' | TC90_LIST 克隆终止 | |
| 任何→物理删除 | PRC_删除员工 | 多表物理删 | TB91 留存(历史档案) | |

## 三、TB91 审核单状态机(ATB912)

```
'1' 暂存 → '2' 提交 → '3' 审核通过
                → '4' 审核不通过 → (bgcl 重提) → '2' → '3'
```

| ATB912 | 含义 | 驱动 |
|---|---|---|
| '1' | 暂存 | tdbaService.update |
| '2' | 提交待审 | tdbaService.doCommit / bgcl 重提 |
| '3' | 审核通过 | PRC_COMFIRM_SH '3' |
| '4' | 审核不通过 | PRC_员工批量审核不通过 |

**ATB91Z**: 始终=TC90.ATC900(关联键)，审核通过后 TB91 行留存为历史档案。

## 四、ATC9W8 状态机(社保/医保明细表 TC9W/TC9W1/TC9W2)

| ATC9W8 | 含义 | 驱动 |
|---|---|---|
| '1' | 已生成(待回盘) | PRC_社保报增员工 / PRC_市医保报增员工 |
| '4' | **已回盘(锁)** | 回盘提交; 存在'4'行→同月不可重新生成 |

## 五、AAE100 主记录有效标志

| 值 | 含义 | 驱动 |
|---|---|---|
| '1' | 有效 | 默认 |
| '0' | 无效 | 终止申请**即时置 0**(提交未审即失效——遗产行为) |

## 六、并发约束与业务校验链

| 校验 | 过程 | 拒绝消息 |
|---|---|---|
| 经办人存在于 SYS_ORG_USER_UNIT | 多数 proc | 获取经办人信息出错 |
| 户头存在于 AA03 | 多数 proc | 查询险金户头信息出错 |
| 业务年月非空 | 报增/报减 | 业务年月不能为空 |
| 当月未回盘(ATC9W8≠'4') | 报增重生成 | 当月数据已经回盘 |
| 当月未结算(TC93 无当月行) | 参保地变更 | 单位已经结算，请下月再办理 |
| 已生成工资 | PRC_删除员工 | 拒绝删除 |
| ATC90PA='0'(医保参保完成) | 参保地变更(医保) | 医保未参保成功 |

## 七、克隆-终止模型(结构性语义)

| 场景 | 模型 |
|---|---|
| 结算单元调转('26') | TC90_LIST 克隆(新单元)→审核→克隆生效('3'/'1'), 旧行不动 |
| 参保地变更 | TC90 克隆(新参保地)→旧行终止('5')+新行生效('3'), **TC90_LIST 层面操作** |
| 工资细项修改(AA90) | isModify 行→新实体插入(新 PK)→旧行物理删——**换行式修改** |
