# 004 - V2 部署缺失文件导致登录 500 错误

**日期**: 2026-08-18
**问题**: V2 Tomcat (port 8081) 登录时报 HTTP 500，NullPointerException in `LoginAdapter.loadUserByUsername`
**原因**: V2 tar.gz (`rcpq-base-v2.tar.gz`) 是从 `src/main/webapp/` 创建的，缺少了原 Tomcat 中 `WEB-INF/classes/` 下的配置文件和 `ts/`、`lemis/` 目录下的部分文件

---

## 根因分析

V2 tar.gz 打包时只包含了 `src/main/webapp/` 下的源码文件，但原 Tomcat 的 webapp 还包含：
1. **编译后的配置文件** (`WEB-INF/classes/*.properties`, `*.xml`)
2. **系统配置目录** (`ts/config/`)
3. **数据源定义文件** (`.ds.js`)
4. **静态资源** (GIF, PNG, JPG)

这些文件在部署时由 Tomcat 从原始安装包解压得到，不在 git 仓库中。

---

## 修复方法

```bash
# 从 V1 复制缺失文件到 V2
V1=/opt/apache-tomcat-8.5.100/webapps/rcpq
V2=/opt/apache-tomcat-8.5.101/webapps/rcpq

# 1. 复制 properties 和 xml
for f in appenders.properties AppError.properties commons-logging.properties \
  hibernate.properties log-config.properties LogInfo.properties \
  logListener.properties org-config.properties org-notify.properties \
  purviewcopy.properties Struts-Layout_default.properties \
  unieap-version.properties unieap_workflow_en.properties \
  unieap_workflow_ja_JP.properties unieap_workflow_zh_CN.properties \
  log4j.xml; do
  sudo cp "$V1/WEB-INF/classes/$f" "$V2/WEB-INF/classes/$f"
done

# 2. 复制 ts/ 目录
sudo cp -r "$V1/ts" "$V2/"

# 3. 同步 lemis/ 目录
sudo rsync -a --ignore-existing "$V1/lemis/" "$V2/lemis/"
```

## 教训

**下次创建 tar.gz 时，必须从完整的 Tomcat webapp 目录打包，不能只打包 `src/main/webapp/`。**

应该执行：
```bash
# 正确的打包方式
tar czf rcpq-base-v3.tar.gz -C /opt/apache-tomcat-8.5.100/webapps rcpq/
```
