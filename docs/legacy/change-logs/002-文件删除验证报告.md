## 详细验证结果

### 阶段 1a: ext-1.1 旧版框架 (235 文件) — ✅ 安全

**验证方式**: grep 搜索 `ext-1.1` 在所有 JSP/HTML/JS/XML 文件中的引用

**结果**:
- 仅发现 2 处代码注释引用，均指向 `extjs.com` 外部链接，非本地加载
- 零 `<script src="...ext-1.1...">` 加载语句
- 零 `<link href="...ext-1.1...">` 样式引用
- 系统使用的是 `ext-3.x` 版本，`ext-1.1` 为历史遗留

**文件路径**: `/unieap/js/ext/ext-1.1/`

**安全删除**: ✅ 是

---

### 阶段 1b: webdesign/ext-1.1.1 (386 文件) — ❌ 不可删除

**验证方式**: grep 搜索 `ext-1.1.1` 在所有 JSP/HTML/JS 文件中的引用

**结果**:
- 发现 **16 个 JSP/JS 文件** actively load ExtJS 核心文件:
  - `Ext.js` (ExtJS 核心)
  - `ext-base.js` (ExtJS 基础库)
  - `ext-all.css` (ExtJS 样式表)
- 这些文件属于 **UniEAP 工作流流程设计器** (workflow webdesign)
- 删除后流程设计器页面将完全无法渲染

**关键引用文件** (部分):
- `unieap/pages/workflow/webdesign/*.jsp` — 加载 ExtJS 核心
- `unieap/pages/workflow/webdesign/*.js` — 依赖 ExtJS 组件

**结论**: 这些文件不是冗余副本，而是 **工作流子系统的核心前端依赖**。必须保留。

---

### 阶段 1c: FCKeditor _source + 非 Java 连接器 (151 文件) — ✅ 安全

**验证方式**: grep 搜索 FCKeditor 文件引用

**结果**:
- Java 连接器（`FCKeditor connector Java`）和核心文件无引用
- `_source/` 目录为开发源码，生产环境不需要
- 非 Java 连接器（PHP/ASP/ASP.NET）在 Java 项目中不可能被使用

**安全删除**: ✅ 是

---

### 阶段 2: images 去重副本 (563 文件) — ✅ 安全

**验证方式**: SHA-1 哈希去重 + 零引用验证

**结果**:
- 所有 563 个文件与保留文件的 SHA-1 完全相同
- 这些是冗余副本，非独立文件
- 零外部引用指向这些副本路径

**安全删除**: ✅ 是

---

### 阶段 3: ts/ Flash 触摸屏终端 (293 文件) — ✅ 安全

**验证方式**: grep 搜索 `ts/` 在 JSP/HTML/XML 中的引用 + HTTP 404 验证

**结果**:
- 无外部引用指向 `ts/` 目录下的任何文件
- `TerminalRedirectServlet` 已在 `web.xml` 中注释掉
- HTTP 404 验证确认这些文件确实已被访问不到

**安全删除**: ✅ 是

---

### 阶段 4: ds.js 孤儿变体 (18 文件) — ✅ 安全

**验证方式**: grep 搜索 `ds.js` 在 JSP/HTML 中的引用

**结果**:
- 无外部引用指向这些孤儿变体
- 系统使用的是标准 `ds.js`，这些是历史遗留副本

**安全删除**: ✅ 是
