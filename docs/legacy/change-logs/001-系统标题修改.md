# 修改记录 001：系统标题从 "Lemis" 改为 "彩虹人才管理系统"

- **日期**：2026-08-18
- **操作环境**：/opt/apache-tomcat-8.5.100/webapps/rcpq
- **涉及版本**：rcpq-base.tar.gz（编译后 class 覆盖部署）

---

## 背景

原始系统由东软在 UniEAP 框架上开发，系统标题硬编码为 "Lemis"（东软人才派遣管理系统的内部代号）。需要替换为实际业务名称"彩虹人才管理系统"。

## 修改涉及的文件

通过数字后缀标记法逐一验证了每个 title 标签的实际生效位置：

| # | 文件路径 | 是否实际修改 | 实际生效位置 |
|---|----------|-------------|-------------|
| 1 | `lemis/pages/index.jsp` | ✅ 改为 `彩虹人才管理系统` | **登录后浏览器 tab 标题**（主入口页面） |
| 2 | `lemis/pages/mainFrame.jsp` | ❌ 保持原值 `Lemis` | 内嵌 iframe 框架页（用户不可见） |
| 3 | `lemis/pages/menu/RootMenu.jsp` | ❌ 保持原值 `Lemis` | 内嵌 iframe 菜单栏区域（用户不可见） |
| 4 | `WEB-INF/applications.xml` | ❌ 保持原值 `lemis` | 框架内部应用名（菜单/多应用切换，页面不直接显示） |
| 5 | `unieap/pages/login/login.jsp` | ✅ 改为 `彩虹人才管理系统` | **登录页浏览器 tab 标题** |

### 验证方法

用数字后缀标记法定位：给每个文件的 `<title>` 加不同后缀（-1 ~ -5），然后 curl 访问各 URL，grep `<title>` 确认哪个后缀出现在哪个页面：

```bash
# 登录页 → 显示 -5（login.jsp）
curl -s "http://localhost:8080/rcpq/login.do?method=begin" | grep "<title>"
# <title>彩虹人才管理系统-5</title>

# 登录后主页面 → 显示 -1（index.jsp）
curl -s ... "http://localhost:8080/rcpq/enterapp.do?method=begin&name=/lemis&welcome=/lemis/pages/index.jsp" | grep "<title>"
# <title>彩虹人才管理系统-1</title>

# mainFrame → 显示 -2
curl -s ... "http://localhost:8080/rcpq/lemis/pages/mainFrame.jsp" | grep "<title>"
# <title>彩虹人才管理系统-2</title>

# RootMenu → 显示 -3
curl -s ... "http://localhost:8080/rcpq/lemis/pages/menu/RootMenu.jsp" | grep "<title>"
# <title>彩虹人才管理系统-3</title>

# applications.xml → 页面不直接显示（框架内部标识）
```

### 结论

**浏览器 tab 标题由 `lemis/pages/index.jsp` 的 `<title>` 决定**。用户在浏览器标签上看到的标题就是这个文件里的内容。`applications.xml` 的 `<title>` 是框架内部标识，不在页面上直接渲染。
