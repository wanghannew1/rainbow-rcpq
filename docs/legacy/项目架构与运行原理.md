## 2. Tomcat 工作原理

### 2.1 Tomcat 是什么？

Tomcat 是 **Servlet 容器**，不是静态文件服务器（如 nginx）。它能：

- 执行 JSP（编译并运行 Java 代码）
- 执行 Servlet（处理业务逻辑）
- 提供静态文件服务（JS/CSS/图片）

### 2.2 静态文件 vs 动态文件

```
浏览器请求
    ↓
Tomcat 判断文件类型
    ↓
┌─────────────────────────────────────────┐
│  静态文件 (JS/CSS/HTML/图片)              │
│  → 直接读取文件，返回给浏览器              │
│  → 和 nginx 一样                         │
├─────────────────────────────────────────┤
│  动态文件 (JSP)                          │
│  → 编译成 Java Servlet                   │
│  → 执行 Servlet，生成 HTML                │
│  → 返回 HTML 给浏览器                     │
└─────────────────────────────────────────┘
```

### 2.3 JSP 编译流程

```
第一次访问 login.jsp
    ↓
Tomcat 查找: webapp/lemis/pages/login.jsp
    ↓
编译: login.jsp → login_jsp.java → login_jsp.class
    ↓
存储: work/Catalina/localhost/rcpq/org/apache/jsp/
    ↓
执行 login_jsp.class → 生成 HTML
    ↓
返回 HTML 给浏览器

第二次访问 login.jsp
    ↓
直接执行 login_jsp.class（缓存）
    ↓
返回 HTML 给浏览器
```

**关键点**：
- JSP 由 Tomcat 在**第一次被访问时**编译，不是 Maven 编译
- `mvn compile` 只编译 `src/main/java/` 下的 `.java` 文件
- JSP 编译后的 class 存储在 `work/Catalina/localhost/rcpq/` 目录下

### 2.4 Struts 路由机制

这个项目使用 **Struts 1.2.7** 作为 MVC 框架，不是直接访问 JSP：

```
浏览器请求: /rcpq/login.do?method=begin
    ↓
web.xml → ActionServlet (Struts 核心)
    ↓
struts-config.xml → 路由到 LoginAction
    ↓
LoginAction 处理业务逻辑
    ↓
转发到 /unieap/pages/login/login.jsp
    ↓
JSP 编译执行 → 返回 HTML
```

## 4. URL 与目录对应关系

### 4.1 基本映射

```
浏览器 URL                              Tomcat 查找路径
─────────────────────────────────────────────────────────
http://host:8080/rcpq/                  → src/main/webapp/
http://host:8080/rcpq/login.do         → struts-config.xml → LoginAction
http://host:8080/rcpq/lemis/pages/az/az01.jsp
                                        → src/main/webapp/lemis/pages/az/az01.jsp
http://host:8080/rcpq/unieap/js/treehandle.js
                                        → src/main/webapp/unieap/js/treehandle.js (静态)
http://host:8080/rcpq/unieap/images/logo.gif
                                        → src/main/webapp/unieap/images/logo.gif (静态)
```

### 4.2 Context Path

- Context Path: `/rcpq`（在 Tomcat 的 `server.xml` 中配置）
- 所有 URL 都以 `/rcpq` 开头
- webapp 目录结构 = 浏览器 URL 路径（去掉 context path）

### 4.3 不可访问的目录

```
http://host:8080/rcpq/WEB-INF/         → ❌ 403 Forbidden
http://host:8080/rcpq/WEB-INF/lib/     → ❌ 403 Forbidden
http://host:8080/rcpq/WEB-INF/classes/ → ❌ 403 Forbidden
```

Tomcat 安全机制禁止直接访问 `WEB-INF/` 目录。

## 5. Struts 路由配置

### 5.1 struts-config.xml 位置

```
src/main/webapp/WEB-INF/struts-config.xml  ← Tomcat 实际使用
src/main/resources/struts-config.xml       ← Maven 资源（相同内容，不同行尾）
```

### 5.2 路由示例

```xml
<!-- 登录 Action -->
<action type="com.neusoft.lemis.cp33.action.LoginAction"
        parameter="method,secure" scope="request" path="/login">
    <forward name="begin" path="/unieap/pages/login/login.jsp" />
    <forward name="success" path="/index.jsp" />
    <forward name="error" path="/unieap/pages/login/error.jsp" />
</action>
```

**forward 路由说明**：
- `name` = Action 方法返回值（路由键）
- `path` = webapp 根目录的相对路径（从 `/` 开始）

```
LoginAction.begin() 返回 "begin"
  ↓
forward name="begin" → path="/unieap/pages/login/login.jsp"
  ↓
Tomcat 查找: webapp/unieap/pages/login/login.jsp
  ↓
编译执行 → 返回 HTML 给浏览器
```

**登录 Action 的所有 forward**：

| name | path | 说明 |
|------|------|------|
| begin | /unieap/pages/login/login.jsp | 登录页 |
| success | /index.jsp | 登录成功，主页 |
| error | /unieap/pages/login/error.jsp | 错误页 |
| locking | /unieap/pages/login/locking.jsp | 账户锁定 |
| kicked | /unieap/pages/login/kicked.jsp | 被踢出 |
| relogin | /unieap/pages/login/relogin.jsp | 重新登录 |

### 5.3 struts-config.xml 详解

#### 5.3.1 文件结构

```xml
<struts-config>
    <!-- 全局转发（所有 Action 共享） -->
    <global-forwards>
        <forward name="xxx" path="/path/to/jsp" />
    </global-forwards>

    <!-- 路由映射（核心） -->
    <action-mappings>
        <action path="/url-pattern"           <!-- URL 匹配 -->
                type="com.xxx.ActionClass"    <!-- Java Action 类 -->
                parameter="method"            <!-- 方法名参数 -->
                scope="request"               <!-- 作用域 -->
                validate="true">              <!-- 是否验证 -->
            <forward name="result" path="/path/to/jsp" />  <!-- 结果页面 -->
        </action>
    </action-mappings>
</struts-config>
```

#### 5.3.2 action 属性说明

| 属性 | 说明 | 示例 |
|------|------|------|
| `path` | URL 匹配模式 | `/login`, `/m_*` |
| `type` | Java Action 类全名 | `com.neusoft.lemis.cp33.action.LoginAction` |
| `parameter` | 方法名参数 | `method` 或 `method,secure` |
| `scope` | 请求作用域 | `request` 或 `session` |
| `validate` | 是否启用表单验证 | `true` 或 `false` |
| `forward` | 结果页面转发 | `<forward name="success" path="/index.jsp" />` |

#### 5.3.3 路由匹配规则

**精确匹配**：
```xml
<!-- /login.do 只匹配 /login -->
<action path="/login" ... />
```

**通配符匹配**：
```xml
<!-- /m_* 匹配 /m_xxx.do -->
<action path="/m_*" ... />
```

**方法参数**：
```xml
<!-- /login.do?method=begin → 执行 begin() 方法 -->
<!-- /login.do?method=success → 执行 success() 方法 -->
<action path="/login" parameter="method" ... />
```

### 5.4 请求处理流程

```
1. 浏览器: GET /rcpq/login.do?method=begin
                     ↓
2. Tomcat: 解析 .do 后缀 → 转发给 ActionServlet
                     ↓
3. ActionServlet: 查找 struts-config.xml
   - 匹配 path="/login"
   - 找到 type="com.neusoft.lemis.cp33.action.LoginAction"
                     ↓
4. LoginAction: 
   - 读取 parameter="method" → 获取 method=begin
   - 执行 begin() 方法
   - 返回 ActionForward
                     ↓
5. ActionForward: 
   - forward name="begin" → path="/unieap/pages/login/login.jsp"
                     ↓
6. Tomcat: 
   - 编译 login.jsp → login_jsp.java → login_jsp.class
   - 执行 login_jsp.class → 生成 HTML
   - 返回 HTML 给浏览器
                     ↓
7. 浏览器: 显示登录页面
```

### 5.7 关键点总结

1. **URL 模式**：所有请求以 `.do` 结尾（Struts 1.x 约定）
2. **方法路由**：通过 `parameter="method"` 实现一个 Action 多个方法
3. **结果转发**：Action 返回 `ActionForward`，指定跳转到哪个 JSP
4. **JSP 编译**：第一次访问时编译，后续直接执行
5. **作用域**：`request`（单次请求）或 `session`（会话级别）

### 5.3 请求流程

```
1. 浏览器: GET /rcpq/login.do?method=begin
2. Tomcat: 解析 .do 后缀 → 转发给 ActionServlet
3. ActionServlet: 查找 struts-config.xml 中 path="/login" 的 action
4. LoginAction: 执行 begin() 方法
5. 返回: forward name="begin" → /unieap/pages/login/login.jsp
6. Tomcat: 编译 login.jsp → 执行 → 返回 HTML
7. 浏览器: 显示登录页面
```

## 8. 总结

1. **Tomcat 是 Servlet 容器**：JSP 由 Tomcat 在运行时编译，不是 Maven 编译
2. **Struts 负责路由**：URL → Action → JSP，不是直接访问 JSP
3. **webapp 目录 = 浏览器 URL**：去掉 context path `/rcpq` 后直接对应
4. **WEB-INF 不可访问**：安全机制禁止浏览器直接访问
5. **静态文件直接返回**：JS/CSS/图片和 nginx 一样直接返回
6. **JSP 运行时编译**：第一次访问时编译，后续直接执行
