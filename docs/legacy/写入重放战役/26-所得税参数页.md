# 写入重放战役 26 — tdga 所得税参数页: 首个遗产 bug 实修闭环(2026-11-21, jiaq)

## AA92 起征点参数 — 发现 bug → 修复 → 部署 → 实测验证 全闭环 ✅

**遗产 bug**: `AA92.hbm.xml` 的主键映射自相矛盾——AAA921 列是 VARCHAR2(3) 的"参数项目"
人工代码, hbm 却声明 `type="java.lang.String"` + `<generator class="sequence">`。
**String 主键 + 序列生成器** = hibernate 必抛 "Unknown integral data type for ids :
java.lang.String" → **tdga 新增参数功能自始不可用**(与幽灵过程/坏引用同级的死功能)。

**修复**(仓库+8091 部署份同步): 移除 hbm 的 sequence 生成器(主键改人工赋值, 与列语义一致);
实体影子类 String 类型**还原确认正确**(初判"反编译类型 bug"系误诊, 真凶是 hbm 配置——
一次有价值的误诊纠偏)。重启后实弹: AAA921='ZZZ' 参数值=3 **落库验证**, 清理回归 2 行基线。
