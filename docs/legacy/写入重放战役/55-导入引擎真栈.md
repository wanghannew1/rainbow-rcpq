## 五、真栈捕获(悬案终局)

```
java.lang.ClassCastException: org.hibernate.collection.PersistentSet cannot be cast to java.util.List
	at com.neusoft.lemis.cp33.utils.dao.ImportUtil.doExcelImport(ImportUtil.java:231)
```

**字节级铁证**(影子类反汇编):
```
310: invokevirtual SYS_IMPORT.getSysImportMappings:()Ljava/util/Set;
313: checkcast     java/util/List        ← Set 强转 List, 必炸
```
hbm 映射 `<set name="sysImportMappings">` → 运行时 PersistentSet → 旧版二进制 cast 成
List → **每个 importId、每张模板、必然即死**。

**根因 = 陈旧影子类**: `WEB-INF/classes/.../ImportUtil.class`(11-21 部署副本携带, 老编译版)
遮蔽了 cp33.jar 里的**修复版**(jar 自带源码已按 Set 迭代) — 类加载顺序 classes 优先 →
旧二进制永久压制新代码。与记忆中"27 遮蔽类陷阱"同族, 但 ImportUtil 的强转坑在影子版里
并未修过(记忆中"已修 3 例含 ImportUtil"系误记, 实修的是 PojoUtil/ConvertionUtil 等)。

**修复 = 删除影子 .class, 让 jar 版加载** → 立即 `{succeed:true,ce10:[60314],baz002:9826597,errors:[]}`
→ CE10 批次登记 ✓ + TC90_BP1 暂存行落库 ✓ → 测试批次已清场(0 残留)。
