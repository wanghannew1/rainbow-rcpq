## 二、结论

1. **PKG_费用结算编译复活后六 proc 全部可执行** — 卷 20/34 的"解锁"落地为通道级验证。
2. 幻影分型给重写指明契约: 结算类 proc 以单元存在为先决条件, 应返回业务错误(appCode=-1 "单元不存在")而非裸 ORA-01403。
3. **真实值结算测试需合成派遣单位夹具**(AB01+TB90+TC90 人+月数据) — 列为卷 38+ 大项。
4. tdcc 模板 proc 语义: `DELETE TC0A_BP01 WHERE atb930=单元` 后按 TC90(ATC90W='0', 同单元)重建 — 幻影时 DELETE 0 行+INSERT 0 行, 已验。
