## 二、重大遗产缺陷(定性)

### 1. PRC_终止劳务派遣服务统计表 = 永远坏
源码 323~621 行: `INSERT INTO TJ0Z1 VALUES R_TJ`(:606) 但 **R_TJ.TJID 全程零赋值**(无 SYS_GUID,
对比同包 :45/:733 均有), TJ0Z1.TJID 无默认值, PK → **任何月份任何数据必然 ORA-01400**。
生产上"终止劳务派遣服务统计"报表**从未成功过**(6979 行全为经营统计表所写)。
脚本对该缺陷做断言用例(500+日志 ORA-01400), 重写时应修复(TJID := SYS_GUID())。

### 2. tdhab 页 = 死菜单
页面 JS 调 `PKG_统计报表.PRC_派遣保险统计` — **该过程在 user_arguments 0 命中**(不存在) →
PLS-00302 → 500。页面本身渲染正常但功能必死。
