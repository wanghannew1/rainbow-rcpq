## 二、新形状律(入档)

1. **DC 行状态键 `_t`(ria3.3 Row.js 反编译源)**: `1=NEWMODIFIED(新增) / 2=NOTMODIFIED(缺省!) /
   3=DATAMODIFIED(修改)`。**不带 `_t` 的行=2, 路由静默跳过** — HTTP 200 + recordCount 回显
   + 库 0 行的"空转保存"即此因。修改行还带 `_o`(原值)。
2. **删除协议**: 页面 doDel=deleteRow→行进 `rowSet.delete` 数组, 须**整行**(与整行保存律同源)。
3. **查询条件**: 客户端 createCondition 产裸 SQL 片段, 列名=**绑定键小写**(大写查不到, 不报错);
   DC 响应是裸键非严格 JSON(解析用子串计数)。
4. **日期上写**: 必须 epoch 毫秒(卷01律6 再证); 字符串日期→`For input string` 被
   "记录日志错误"掩码。
5. **后台校验按页 ds 的 nullable:false 白名单**: tdim 独有必填 atc031(劳动鉴定申报日期)/
   atc032(伤残等级)/atc033(一次性伤残补助金) — 缺则 -30050; hbm 非空(ATC020/900/AAC001)
   与 ds 必填是**两套**, 交集都须满足。
