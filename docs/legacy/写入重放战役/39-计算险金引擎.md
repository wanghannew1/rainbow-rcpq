## 二、本轮排障链(为什么曾算出 0)

1. 比例 OUT 实证法: 匿名块+EXECUTE IMMEDIATE 落临时表(静态 INSERT 会 ORA-00942 编译错) →
   `获取缴费比例_按员工` 返回 ATB90K=16 ✓ — AA94 夹具有效。
2. 隔离调 `计算险金`: rate=16/base=2800 流入但 bba001=0 → 定位到 ⑨ 清零门。
3. **根因**: 模板人 atc90p='1'(停保态) + 卷 35 年月归一化把停缴年月 AAA209 改成结算月 →
   `ATC90P='1' AND AAA209≤年月` 命中 → 养老清零(全险种同构连坐)。
4. 修复: 旗标全 '2'(在保) + 停缴年月族(aaa203/204/208/209/503/504/508/509/603/604/608/609)统一置结算月前 →
   bba001=448(2800×16%), bba002=36.4, baa200=476 — 引擎活体验证。

## 三、遗产缺陷/重写须知

1. **生育清零门读 AAA402(医保旗标)而非 AAA405(生育旗标)** — 列漂移(830-851 行), 与卷 36 工伤/公积金同属一族。
2. atc90pa 被"医保/工伤"两险种共用为状态旗标(atc90p 养老/atc90w 公积金/atc90pa 医保+工伤/atc90pb 工伤), 语义耦合脆弱。
3. 上下限 proc 缺行时静默不钳制(无告警) — 超限基数可入账; 与卷 36 上下限校验注释禁用互证。
4. 重写规格 05(工资计算)应把"参保状态门"显式建模为: 参保旗标 × 在保状态 × 停缴年月 三元组, 而非散落 IF。

## 四、夹具要点(重放测试资产)
