## 二、关键机制(重写依据, 全部实测定名)

1. **导入引擎契约**: multipart 四字段(importId/javabean/parameters JSON/文件任意名);
   parameters 逐键 BeanUtils 盖章进每暂存行(atb930/atb900/aab001/aab004 即由此来);
   mappingCell=**列号**(0 起), startingRow=SYS_IMPORT.**DATA_FROM 列**(hbm 属性名陷阱,
   tc90_impdel=4); 物理行数与 startingRow 决定读取窗; 长度超标行**照存**且 succeed:false。
2. **必填五项**(校验过程缺一即 ace10a=2 + 逐项中文清单回写 ace10b): 列3 AAE003 资料提交年月
   (yyyymm), 列8 ATC90K 终止原因(AA10 码, 09=职工个人原因), 列9 ATC90L 失业金(0/1),
   列10 ATC90AV 工资结束年月(yyyymm), 列11 ATC90N 经济赔偿(0/1)。
   判别: 按时段限(AAE00P IN 1,5)与险种旗标(AAA401/402/404/407='1')才验报减年月格式/时限。
3. **状态机语义勘定**: 提交过程直接 ATB90R 3→**5(=终止生效终态, 卷03 状态机)**, 非字面
   "提交审核"; TB91.ATB912='3'=待审轨迹。tdbd 审核页终止类按钮(员工终止审核_批量)实为
   **确认/补记审核人**(再置 5 + 审计列), 非状态翻转。
4. **形状律⑤新例**: 员工终止审核_批量 对行级异常 `WHEN OTHERS` 吞成 appCode=1 —
   **返回码不可信, 断言必须落 DB 状态**; 重写应结构化报错(升级点)。
5. 卷54 结论再证: proc 通道 paraOutType=[] 万能(本卷 4 过程全用 [])。
