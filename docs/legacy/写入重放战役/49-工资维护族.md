## 二、新配方定律(卷49 定型, 补卷48 形状律)

1. **自定义服务按 PK 空判定插入/更新**(doSaveAa80/doSaveAa81 反汇编: `getAaa810()==null
   ? save : saveOrUpdate`) — **带主键的新行走 saveOrUpdate=UPDATE 0 行静默无操作**。
   插入行一律**不带主键**, 序列配号后从 DB 回读。
   (卷48 的 TC02 路由通道 `createPojoList` 按 `_t` 分类, 带不带主键都能插 — 两套机制并存!)
2. **无主键插入时序列替换一切显式 id** — 验证必须用标记列(AAE013/组合条件), 不可用合成主键。
3. **会话首发热身怪癖**: 同 payload 首发静默丢/批内重复配号 ORA-00001(部分提交), 重发即成 —
   套件统一"无效果重发一次"。
4. **AA98 无 AAE013 列** — 标记列按表定制。
