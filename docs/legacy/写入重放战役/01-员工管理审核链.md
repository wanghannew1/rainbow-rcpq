## 本链新知识(重写必读)

### 服务端行为语义(tdbaService.java, 125 行全读)
1. **tc9eStore.getRowDataObjs().get(0) 无条件取行**——空 rowSet 直接 IndexOutOfBounds→title-less 异常→:83 崩。**不补缴也必须给一行**(`{}` 即可, 服务端按 atc90ai/atc90at 非'1'跳过写 TC9E)。
2. 暂存顺带 `UPDATE AC01 SET bbb001/bbb002 WHERE aac001=tc90.aac001`(银行账号回写人员主档)——aac001 不存在时 0 行更新静默过。
3. 新增分支(atc900=null): hibernate 配号 TC90.ATC900 → TB91.ATB91Z=ATC900 回链 → TB91 配号 ATB910 → 回填 TC90.ATB910。
4. doCommit 极薄: 仅置 atb90r='2'/atb912='2'(报增年月 aaa201/aaa501 是**客户端 JS** 按 AAA95 异动日算的, 服务端不管)。
5. **错误数据删除后 TB91 留存**(doDel 只发 proc, 无 TB91 删除)——审核单=历史档案, 重写须保留此语义。

### 载荷形状律(新增三条)
6. **日期列必须发 epoch 毫秒数值**, 发字符串("1992-02-15 00:00:00.0")→ HibernateHelper NumberFormatException。JDBC getString 抄数时全部要转换。
7. **实体元数据必填 ≠ DB 非空**: TC90 表仅 4 列真非空, 但 ds.js 元数据 25 列 `nullable:false` 被 metadata_validate 过滤器强制(-30050 后台校验错误+`[是否参加大额医疗保险]数据不可为空`直接点名)。取材方法: 解析页面 .ds.js 的 nullable:false 与模板行求差补齐(本次实缺 aaa408 一列)。
8. **proc paraOutType 必须恒 `[]`**(勘正旧记忆①): helper 自动按 user_arguments 装配 OUT; 显式给类型会多拼形参 → `PLS-00306 参数个数或类型错误`(活库签名明明一致也炸)。tdca(5IN)与 COMFIRM_SH(7IN)双例验证。

### 排障指纹增补
9. `-30050 后台校验错误` + 下一行 `[字段label]数据不可为空` = 元数据校验, 错误文本在 LemisException.printStackTrace 的 ERROR 块(先 grep 时间戳定位行号再 sed 展开)。
10. `LemisBusinessException 异常: -30030 交互[...]调用出错: null` + 上文 ORA-06550/PLS-00306 = proc 形参装配错(见律 8)。
11. 业务拒绝(过程 OUT appCode=-1)会 `LemisBusinessException("存储过程[...]指定回滚", errMsg)`——**有 title**, 不炸 :83, 走 200 结构化应答。
