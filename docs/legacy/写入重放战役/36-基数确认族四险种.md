## 二、业务链路实读+实测(PKG_缴费基数 634~1700 行)

```
AA97 批次行(单位申报导入产生, 90 列)
  → PRC_X缴费基数核对(年度,户头,区划)      [3IN+2OUT]
      幂等: 有 AAE214_x='1' 行 → 直接 RETURN OK
      逐行: 按 AA97.ATC900 查 TC90 → 行级门槛 → 过: AAA3xx=TC90 原基数同步, AAE214_x='3'
                                      → 不过: E_EXCEPTION → AAE214_x='0'(继续不中断, appCode 仍 1)
      (应申报未申报 INSERT 段在社保版未注释 — 本测用隔离作用域使其零命中)
  → PRC_X缴费基数确认(年度,户头,区划,生效年月,经办人) [5IN+2OUT]
      先调核对(不过即返回) → 游标只取 AAE214_x='3' 行
      → UPDATE TC90 SET 该险种基数列 = AA97 新基数列 WHERE ATC900=(max(atc900) 同 aac001 在保行)
      → UPDATE AA97 SET AAE214_x='1', 盖经办人/机构/时间戳
```

## 三、新形状律(续卷 35)

**㉓ 区划列按险种漂移**: 核对/确认游标的区划匹配列 — 社保=AAA100, 医保=**AAA110**, 公积金=**AAA120**, 工伤=**AAA120(与公积金同列!)**。批次行必须把 AAA100/110/120/130 四列填齐, 否则行根本进不了游标(状态留 NULL, 静默不处理)。

**㉔ 行级门槛读不同旗标列**: 社保门槛读 **ATC90P**, 医保门槛读 **ATC90PA**(命名漂移: 医保用公积金旗标列)。共同万能分支 = `旗标='2' AND ATB90R='3'`(AAA4xx='1'+旗标 NULL+AE002<年初 为辅助分支)。测试人四旗标全置 '2' 后四险种门槛全命中。

**㉕ 核对-确认状态机**: `NULL(待核对) → '3'(已核对,同步原基数) → '1'(已确认,TC90 落新基数)`; 异常行 `'0'`(核对失败, 不阻断批次); **确认只认'3'**, 核对对'1'幂等跳过。重写须按此实现且失败行要可见(旧系统'0'行无提示)。

**㉖ AA97 批次行可 JDBC 直造**: 主键 AAA970 显式赋值无序列依赖; 最小列集 `AAA970/AAE001/AAB001/AAB004/AAA030/AAA100~130/ATC900/AAC001/AAC003/AAC002/<险种新基数列>`。

**㉗ 隔离作用域三件套**: 假户头('999x', 生产未用)+假区划('209900000000')+未来年度(2099) — proc 全部按(户头,区划,年度)三维过滤, 三者皆合成即生产零接触; 清场谓词 `AAA030 IN ('999x')`。
