### 卷 30 遗留谜终解: bgcl 为什么 500

`tdbf_dialog_bgcl.js` 实读(bgcl=变更处理弹窗, tdbf 审核处理页调出):
- **它是变更链专用**: resetForm 按 `atc920 = atb91z` 查 TC92(:436-439), 再取 `getRow(tc92Store_cbcl,0)`——新签链(ATB911='20')根本没有 TC92 行, **浏览器端 JS 自己就会崩**; 卷 30 从 HTTP 层复刻永远复刻不通, 因为生产用户也走不到这。
- 再提交实线 = `tb91Store(atb912→'2', aae013='于<日>再次提交') + tc92Store_cbcl` 复合 saveWithOther(:37-44)。
- **新签链打回后的真实重提通道 = tdba 页面的同一个 commit 交互**(doCommit 无条件 atb912→'2'), TC-005 据此实现并闭合 '2'→'4'→'2'→'3'。
