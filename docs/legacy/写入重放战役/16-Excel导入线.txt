## 传输合同(逆向完成, 可直接用于重写的导入通道设计)

- 端点: `POST /rcpq/ria_pojo.do?method=doImport`, **multipart/form-data**
- 字段: **uploadFile**(文件, unieap FileInput 默认名) + **importId**(驼峰! 服务端转小写
  存 parameters["importid"]) + javabean(可空) + parameters(JSON 字符串, 可空)
- 响应: 成功 `{succeed:true,ce10:[批次],baz002:N,errors:[]}`;
  Lemis 错误 `{succeed:false,msg:'...'}`; 非 Lemis 异常 `{succeed:false}`(无栈吞掉)
- 服务端链: PojoAction.doImport → 交互 REQ-SysCommon-Import-I(注册在 **SYS_INTERACTION 表**
  之外——cp33.jar 内二进制注册块, bean=LemisGridImportMgr/method=doImport)
  → commons-fileupload 解析 → ImportUtil.doImport:
  SYS_IMPORT(EXPORT 格式) → doExcelImport: SEQ_SYS_BAZ002 取 baz002 → SEQ_CE10_ACE100 批次
  → 按 SHEET_INDEX/起始行(=4)/MAPPING(xls列→实体列, tc90_impdel 16 列)逐行 BeanUtils
  填 TC90_BP1(短列宽记 errors 不阻断) → save → **CE10 批次登记**
- **上传解析引擎是 Java 侧, 与 PKG_IMP 死包无关**——死包只挡"提交"段, 导入段独立可测。
