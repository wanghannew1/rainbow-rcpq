# 彩虹人才管理系统 接口文档 01 — 接口总览与通信协议

> 本文档描述系统的全部 HTTP 接口端点、请求格式、响应格式和错误处理规范。
> 数据来源：33 卷实弹测试 + 653 个注册交互定义 + 20 个 PL/SQL 包签名。

---

## 一、系统架构

```
浏览器 (unieap/dojo JS 框架)
    ↓ HTTP POST
Struts ActionServlet (EAPActionServlet)
    ↓
RPC DispatchAction (RpcDispathAction)
    ↓
PojoAction.action() ← 入口控制器
    ├── ajaxRequest=true → 从 InputStream 解析 DC JSON
    └── 否则 → 从 request.getParameter("data") 解析
    ↓
BusinessDispatcher.dispatch()
    ↓ 按交互 code 查 InteractionBean
    ├── type=Q → bean.method(dc) → 返回 IDataCenter
    ├── type=M → bean.update/doCommit/doImport(dc) → 写库
    └── type=Import → LemisGridImportMgr.doImport(request,response,dc)
    ↓
DataCenterWriter.write(dc) → JSON 响应
```

## 二、接口端点

### 全局统一端点

| 端点 | 方法 | 功能 |
|---|---|---|
| `ria_pojo.do?method=action` | POST | **全部业务操作的统一入口** |
| `ria_pojo.do?method=doImport` | POST(multipart) | Excel 导入 |
| `ria_pojo.do?method=export` | POST | 导出 |
| `ria_pojo.do?method=simpleAjax` | POST | 简单 AJAX |

### 请求格式

```json
{
  "header": { "ajaxRequest": true },
  "body": {
    "dataStores": {
      "<store_name>": {
        "rowSet": {
          "primary": [ { "字段": "值", "_t": 1, "_o": {} } ],
          "filter": [],

        },
        "name": "<store_name>",
        "pageNumber": 1,
        "pageSize": 500,
        "recordCount": 1,
        "rowSetName": "com.neusoft.lemis.apps.entities.baseDB.T.TC90",
        "parameters": {
          "pojo.modelname": "/lemis/pages/xx/yy/xxzz_cont.jsp",
          "pojo.dstype": "POJODS",
          "pojo.usetablealias": "false",
          "pojo.interaction": "<交互code>",
          "pojo.pagename": "<页面名>"
        },
        "condition": "可选查询条件"
      }
    },
    "parameters": {
      "pojo.pagename": "<页面名>",
      "pojo.modelname": "<页面路径>",
      "pojo.dstype": "POJODS",
      "pojo.interaction": "<交互code>",
      "synCount": "false",
      "parameters": { "嵌套业务参数(部分页面用)" }
    }
  }
}
```

### 请求头

```
Content-Type: text/plain
ajaxRequest: true
digest: sha1(escape(body).toLowerCase())
```

⚠ digest 是 ASCII 白名单 escape 后的小写 SHA-1，中文必须用 %uXXXX 转义。

## 三、交互注册表（接口路由）

系统通过 `SYS_INTERACTION` 表（DB）+ `applicationContext-*.xml` 文件（文件）双源注册交互。
每个交互定义了：**code → bean → method** 的路由映射。

### 交互统计
| 统计 | 数值 |
|---|---|
| 注册交互总数 | 653 |
| 类型 Q(查询) | 472 |
| 类型 M(修改) | 181 |
| 涉及页面 | ~150 个 JspBean XML 文件 |
| 涉及 Spring Bean | 27 个 Service 类 |
| 使用最多 | LemisBusinessMgrPoJo(590 个交互的通用处理器) |

### 交互类型

| 类型 | 处理方式 | 说明 |
|---|---|---|
| Q | query | 只读查询，不做写操作 |
| M | update/doCommit/... | 写操作，走事务 |
| Import | doImport | Excel 导入 |

## 五、错误处理规范

> ⚠ 卷 35 实弹勘正: **HTTP 层全线 500** — 以下 -30050/-30022/proc 异常在 wire 上都是
> `500 + JSONException: null object`(EAPActionServlet:862), 错误文本只进 catalina.out 的
> LemisException ERROR 块。旧系统用户只见通用"系统错误"; 下表"错误码"指日志中的真实分类。

| 错误级别 | 日志指纹 | 来源 | 重写处理 |
|---|---|---|---|
| appCode=1, errMsg="" | (proc 应答 200) | 业务层 | 正常 |
| appCode=-1, errMsg=具体原因 | proc 应答 200 结构化 | 过程 OUT 参数 | 200 + 结构化提示 |
| -30050 + [label]不可为空/过长 | 500+日志点名 | hbm/ds nullable 校验 | 200 + 字段级错误(改良) |
| -30030 + ORA-xxxx | 500+日志 | proc 调用 SQL 异常 | 200 + 错误消息(改良) |
| -30022 + 传输的数据被篡改 | 500+日志@ReaderImpl:84 | digest 不匹配 | 修复摘要算法 |
| -30010 primary/filter 不是数组 | 500+日志(记录日志 AOP) | 行形状错误 | 请求校验前置 |
| 500 + JSONException: null | HTTP 层崩溃 | 写出器缺陷 | 错误应答统一 200 结构化 |

## 六、测试用例模板

### TC-001: 员工暂存
```
前置: 无
操作: POST ria_pojo.do?action + interaction=REQ-tdba_cont-save
载荷: 三 store(tc90Store_new+tb91Store+tc9eStore) 各≥1行, _t=1
验证: HTTP 200, TC90 新行 ATB90R='1', TB91 新行 ATB912='1', ATB91Z=ATC900
清理: PRC_删除员工 + TB91 删除
```

### TC-002: 员工提交
```
前置: TC-001 完成
操作: POST interaction=REQ-tdba_cont-commit
载荷: tc90Store_new(_t=3,atb90r='2') + tb91Store(_t=3,atb912='2')
验证: HTTP 200, DB ATB90R='2', ATB912='2'
```

### TC-003: 审核通过
```
前置: TC-002 完成
操作: proc COMFIRM_SH [atb910,'3',经办人,机构,姓名,机构名,区划]
验证: appCode=1, DB ATB90R='3', ATB912='3'
```

### TC-004: 审核不通过
```
前置: TC-002 完成
操作: proc PRC_员工批量审核不通过 [atb910, 经办人]
验证: appCode=1, DB ATB912='4', TC90 不变
```

### TC-005: 打回后重提
```
前置: TC-004 完成
操作: tdba 同一 commit 交互(tb912 4→2, 双 store 全行; bgcl 仅服务变更链——TC92 按 atc920=atb91z)
验证: HTTP 200, DB ATB912='2'; 再审核后 ATB90R='3'/ATB912='3'(状态机 '2'→'4'→'2'→'3' 闭合)
```

### TC-006: 元数据校验-必填缺失
```
前置: 无
操作: 保存行缺必填字段
验证: -30050 + [字段label]数据不可为空
```

### TC-007: 元数据校验-超长
```
前置: 无
操作: 保存行字段值超长
验证: -30050 + [字段label]数据过长
```

### TC-008: digest 错误
```
前置: 故意发错 digest
验证: DataCenterReaderImpl:84 "传输的数据被篡改"
```

### TC-009: 序列冲突
```
前置: 序列值落后于表内数据
操作: 插入
验证: ORA-00001 PK 冲突
修复: NEXTVAL 跳过冲突区
```

### TC-010: proc OUT 参数验证
```
前置: 无

验证: appCode 和 errMsg 语义正确
```
