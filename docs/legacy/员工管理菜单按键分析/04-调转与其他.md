## 7. 菜单外页面 td/b/s（tdbs）

tdbl 的**上一版/平行版**（2020-11 导出 vs tdbl 2021-02）：多「派遣协议信息」面板、查询条件更严（`atb90r='3' and aae100='1'`）、**无同单元校验**。Spring 完整注册、有写库能力（TB91+TC90_LIST，与 tdbl 同一批表），但菜单无入口、无页面链接——**只能手敲 URL 进的影子页**，建议下线或合并。Java：`td/b/s/service/tdblService.java` 与 l 版逐字节相同（仅 package 行差异）。

## 8. 本组公共结论

1. 真正一步写业务表的活 PL/SQL：PRC_CHANGE_EJDW（tdbe）、PRC_保险补收基数_个人（tdbr）、PRC_工资花名册前台（tdbt）；**死活体：PRC_TERMINATE_UNDO（tdbq，注释禁用）**。
2. 调转有两条通道：tdbe=PL/SQL 直接生效（ATB90R 保持 '3'，改单位字段）；tdbl/tdbs=Hibernate 走审核（TC90_LIST 待审行 ATB90R='2' + TB91 ATB911='26'），审核生效靠「审核信息处理」（02 文档）。
3. 状态语义与既有 AA10 字典一致：tdbe 调转池='3' 生效；tdbq 撤销对象='5' 终止；tdbr 补收判定看 ATC90P/PA/W 是否空/'0'。
