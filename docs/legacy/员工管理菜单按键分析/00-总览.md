## 员工管理菜单级结论（重写与运维必读）

1. **最常用页 tdbp 实为「纯导入页」**：五条导入线（新签/解除/未解除更新/续签/新增保险）+ tab2 信息更新已下线；10 个后端过程全部健在，导入质量取决于 ACE10A 校验，续签与未解除更新**无审核直达正式表**。
2. **审核流覆盖不全**：tdbd 查询硬编码过滤 → 22 续签/24 调转审核不可达；tdbf 无 '25' 分支；批量审核静默丢 '27'。'27' 申请入口（tdbb 清单后终止）被隐藏。
3. **假成功死键**：tdbq 撤销解除（PRC_TERMINATE_UNDO 活体被注释）——用户以为恢复成功实际没写库。
4. **三处失业金月数计算连环失效**（PRO_GET_CNT 调用被注释 → atc90l 恒 '0'）：tdbb terminate / tdbf zzcl / tdbd zhongzhi_sh。
5. **调转双轨**：tdbe（PL/SQL 直生效，多选分隔符 bug 只能单选）与 tdbl（TB91 审核制）并存；影子页 tdbs 可手敲 URL 绕过校验。
6. **直改无痕路径**：tdbc jbxx（不审核直改 AC01+TC90，多合同 get(0) bug）、tdbp 更新导入（不写 TB91）。
7. 报表/打印类按键普遍取首行而非选中行（tdbo 三键）。
8. 全组约 20 个死弹窗/死服务通道（入口注释、目标 JSP 缺失、REQ 无调用方），明细见各分组文档。
