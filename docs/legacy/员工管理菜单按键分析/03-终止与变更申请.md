### 弹窗① terminate（终止申请，实际主入口）

- 提交前校验各报减年月≥当月（js:152-171）；资料提交年月按 AA95 异动日自动推下月（js:41-57）。
- **分支 A（劳务 AAE00P='2'）**：直接 `PKG_人才派遣.PRC_合同终止`（✅人才派遣.sql:1883）→ `UPDATE TC90 SET ATB90R='5', ATC90I=SYSDATE, ...`（:1907-1919）——**立即生效、无审核记录、不动 TC90_LIST**。
- **分支 B（派遣/保险代理）**：取序号 `PKG_派遣批量导入.PRC_序列(aaa030,aae003,aaa110,'D')`（✅:3）→ tdbbService.doTerminate：`INSERT TB91`（ATB91Z=atc900、ATB912='2'；ATB911='23' JS 预置）+ `TC90.ATB910/ATB90R←'2'`（tdbbService.java:81-97）；前端同时置 `aae100='0'`、aaa204←aaa202 等报减年月镜像（terminate.js:245-249,379-386）随 saveOrUpdate 落库。
- ⚠ **失业金判定坏键**：`cont`（缴费月数）从未赋值（PRO_GET_CNT 调用被注释 js:391-426）→ `atc90l` 恒置 '0' 不享受失业金（js:331-364）。与 tdbf zzcl、tdbd zhongzhi_sh 三处同源失效。

### 弹窗② zhongzhi（清单后减少，ATB911='27'，入口隐藏不可达）

- 确认 → tdbbService.doZhongzhi：TB91（'27','2'）+ TC90.ATB90R←'2' + **新增 TC93_TF 冲减记录**（tdbbService.java:99-126）；弹窗内查 PRO_GET_CNT（**独立过程存在**：work/pkg_all/PROCEDURE_PRO_GET_CNT.sql）取失业金月数。

### 死窗与死通道

- renew（单个续签）/ renewall（批量续签）/ modify（合同期限变更）三弹窗**入口全被注释**（js:9-12,87-121）；renewall 的服务通道 `REQ-tdbb_dialog_renewall-save` 前端无引用 = 死服务。续签实际走 tdbp「合同续签批量导入」（01 文档）。

- detail（合同详细信息）为活弹窗，被 6+ 个外部页面复用（tdbo/tdcl/tdhm/tdna…）。

### tdbb 风险清单

2. 清单后终止隐藏——'27' 申请入口不可达。

## 二、tdbc 员工信息变更申请

功能：三类变更入口——基本信息直改（不审核）、姓名/身份证送审（'25'）、合同/参保信息送审（'21'）。TC92 镜像列约定：**普通列=变更前快照，`_` 后缀列=变更后新值**。

### 按键表

| 键 [实测] | 通道 | 写库 [代码级] |
|---|---|---|
| 查询 / 重置 | PoJo.query（js:165-180），重置后 atb90r='3' | 无 |

### 弹窗① jbxx（基本信息变更·不审核，身份证/姓名除外）

- 保存 → `TdbcService.changeJbxx`：`AC01 saveOrUpdate` **直接生效** + 把 AC01 约 28 个字段复制到该员工全部生效 TC90 与 TC90_LIST（TdbcService.java:45-117）。
- ⚠ **BUG**：循环内 `tc90List.get(0)` 固定取第一条（:49）——一人多份生效合同时只更新第一份 TC90 却循环 N 次（TC90_LIST 侧用 get(i2) 是对的）。
- ⚠ onComplete 不刷新列表 → 页面 TC90 冗余字段滞后。

### 弹窗② mod1（姓名/身份证变更·送审 '25'）

- 变更前/后对照表单（aac002/aac003/aac004/aac006 镜像列）；新身份证 onBlur 调 `PKG_基本信息.PRC_PARSE_AAC002`（✅）解析 15→18 位/性别/出生并查 AC01 查重（mod1.js:67-126）。
- 保存：**双次 save 互链**——先落 TC92+TB91（atb910=0/atb91z=0），回填后第二次互写 `TB91.ATB91Z↔TC92.ATC920`（js:12-41）。TC90 不动，等 tdbd jbbgsh 审核（九表改身份证姓名）。
- ⚠ 双保存互链脆弱：第二次失败 → 无主 TC92 或无关联 TB91（htbg/mod2/cb 同模式）。

### 弹窗③ htbg（合同/参保信息变更·送审 '21'）

- fieldset：基本信息 / 社保(1) / 医保(2) / 工伤(3) / 公积金(4) / 保险参保信息(5·修改请慎重) / 经办 / 提交审核。几十组「列+列_」镜像初值（htbg.js:465-790，含缴费基数 aaa301~306、参保地 AAA100/110/120/101/111/121、报减年月 aaa202/502/602 等）。
- 保存：TC92+TB91（ATB911='21'/ATB912='2'），TC90 不动 → tdbd bgsh 审核（TC92 "_后"刷进 TC90）。
- ⚠ **未改动也可提交**（用 isValidate 而非 isModifiedAndValidate，js:32；mod1 有「无变更项目!」拦截，htbg 没有）→ 可产生零变更审核单。
- ⚠ 五险一金基数上下限联动函数（AA98 校验 :61-330）全部未 connect（:9-19 注释）且依赖的 atc904 读取也被注释（:2）——「双重死」，htbg 的基数改动无联动校验。
