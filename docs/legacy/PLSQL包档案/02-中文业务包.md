**重写建议**：**第一优先**，且先修后迁。① 立即修：判重前置到 UPDATE/COMMIT 之前＋`PRM_ATC931→PRM_AAE002` 参数修正＋补 `ATC931` 条件——三处改动即可消除高频误报，不必等重写；② 迁移时直接丢弃 L3543-9420 注释区（5,878 行死代码），有效体仅 ~3,500 行，比表面体量小得多；③ 结算主链（TC8G→TC93→TB96→TC8M）金额与状态耦合重，Kotlin 服务层化时按「单元生成→清单生成→确认」拆三个事务边界。
