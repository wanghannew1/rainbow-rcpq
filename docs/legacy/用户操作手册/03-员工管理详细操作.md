## 第一章 系统概述

### 系统定位

这是一套**人才派遣管理系统**，劳务派遣公司将劳动者派遣到用工单位工作。系统管理：

- **单位协议**：与用工单位签订派遣协议
- **员工合同**：与劳动者签订劳动合同，派遣到协议单位
- **社保/公积金/工资**：每月为派遣员工缴纳五险一金、发放工资
- **费用结算**：每月向用工单位收取服务费

### 系统中的核心概念

| 概念 | 说明 | 系统中的体现 |
|---|---|---|
| **结算单元** | 一个用工单位在系统中的登记 | TB93 表，每条 = 一个合作单位 |
| **单位协议** | 派遣公司与用工单位签订的派遣协议 | TB90 表 |
| **个人** | 劳动者基本信息（独立于合同存在） | AC01 表 |
| **员工/合同** | 个人被派遣到某单位的一次雇佣关系 | TC90 主表 + TC90_LIST 明细 |
| **险金户头** | 社保/公积金缴纳的户头 | AA03 表 |
| **审核单** | 每次业务操作的审批记录 | TB91 表 |
| **异动期** | 每月社保增减变动的截止日 | AA95 表 |

### 角色与菜单

| 角色 | 可见菜单 |
|---|---|
| 派遣前台 | 员工管理/异动补退/费用/参数（全模块） |
| 财务管理 | 资金管理/统计查询 |
| 派遣工资 | 工资导入/审核/结算/发放 |
| 派遣社保 | 社保参数/报增报减/基数确认 |
| 派遣医保 | 医保报增报减/基数确认 |
| 派遣公积金 | 公积金基数/上下限 |
| 省工伤 | 省工伤报增报减/回盘 |
| 审批 | 审批相关 |

## 第二章 员工管理操作

### 2.1 新增员工信息申请

**页面路径**：人才派遣管理 → 员工管理 → 新增员工信息申请

**界面上你能看到的按钮**：

| 按钮 | 位置 | 功能 |
|---|---|---|
| 二代身份证读卡 | 表单区 | 连接读卡器自动填入身份信息 |
| 批量导入 | 表单区 | 打开 Excel 导入弹窗 |
| **暂存** | 底部按钮区 | 保存员工信息（未提交） |
| **提交到审核** | 底部按钮区 | 提交给审核员 |
| **删除** | 底部按钮区 | 删除错误数据 |
| 历史合同信息 | 表单区 | 查看该人在其他单位的合同历史 |
| 黑名单 | 表单区 | 将此人加入黑名单 |
| 继续新增 | 表单区 | 保存当前并清空表单继续录入下一人 |
| 更换结算单元 | 表单区 | 切换结算单元 |

**操作步骤（暂存→提交）**：

1. 填写员工基本信息（姓名、身份证号、单位、岗位、工资等必录项）
2. 系统自动检查身份证格式（调 `PKG_基本信息.PRC_PARSE_AAC002` 校验）
3. 如果勾选了"补缴社保/公积金"，填写补缴起止月份 → 系统自动计算补缴金额
4. 点击 **【暂存】**
   - 系统提示"暂存成功，新增员工尚未生效，请及时《提交到审核》"
   - 此时员工状态 = 暂存（ATB90R='1'），数据已入库但未生效
   - 系统同时生成审核单 TB91（ATB912='1'）
5. 核对无误后，点击 **【提交到审核】**
   - 系统弹出确认框"是否确定《提交到审核》？"
   - 如果超过异动日，系统自动将社保报增年月设为下月
   - 员工状态变为提交待审（ATB90R='2'，TB91.ATB912='2'）
   - 系统提示"您当前申请的《新增员工信息》已经提交成功，请等待审核"

**提交后系统自动处理**：
- TC90 新增一条员工合同记录（状态 ATB90R='2'）
- TB91 新增一条审核单（ATB911='20' 新增类型，ATB912='2' 提交待审）
- TB91.ATB91Z 回填员工 ATC900（关联键）
- AC01 表回写银行账号（bbb001/bbb002）

**注意事项**：
- 暂存后**必须提交到审核**，否则员工不会生效
- 提交后如果打回（ATB912='4'），需要重新修改后再提交
- 页面上的身份证号在暂存模式下是只读的（修改身份证要走变更申请）

### 2.2 员工信息审核

**页面路径**：人才派遣管理 → 员工管理 → 员工信息审核

**界面上你能看到的按钮**：

| 按钮 | 功能 |
|---|---|
| 查询 | 按条件查询待审核员工 |
| 清空条件 | 清空查询条件 |
| **批量审核通过** | 勾选多条 → 批量通过（ATB912='3'） |
| **批量审核不通过** | 勾选多条 → 批量打回（ATB912='4'） |
| **单笔审核** | 双击进入详情单笔处理 |
| **撤销合同终止** | 撤销已审核的终止操作 |
| **错误数据删除** | 物理删除错误员工数据 |

**审核通过操作**：
1. 查询待审核员工（勾选"提交未审核"条件）
2. 勾选要审核的员工（可多选）
3. 点击 **【批量审核通过】**
4. 系统按 ATB911 类型分流处理：
   - '20' 新增：员工状态 ATB90R→'3'（生效）
   - '21' 参保变更：TC92 变更后值刷入 TC90
   - '23' 终止：ATB90R→'5'（已终止）
   - '25' 姓名身份证：4 表同步
   - '26' 结算单元调转：TC90_LIST 克隆生效
   - '27' 清单后终止：退费处理+终止

**批量审核不通过操作**：
1. 勾选要打回的员工
2. 点击 **【批量审核不通过】**
3. 系统调用 `PKG_人才派遣.PRC_员工批量审核不通过`
4. TB91.ATB912→'4'，员工退回提交人修改

⚠ **注意**：
- 批量审核通过时 '23' 和 '27' 类型混送会导致 '27' 被静默丢弃（遗产 bug）
- 错误数据删除后 **TB91 留存为历史档案**（不删除）
- 已生成工资的员工无法删除

### 2.3 审核信息处理

**页面路径**：人才派遣管理 → 员工管理 → 审核信息处理

> 这个页面处理审核通过后的后续事务，按审核类型分流到不同弹窗。

| 弹窗 | 审核类型 | 再次提交按钮 | 取消按钮 |
|---|---|---|---|
| xinqcl 新增处理 | '20' | TC90_BG 逐列留痕 + saveOrUpdate | 物理删 TC90+TB91 |
| bgcl 变更处理 | '21' | TB912←'2' 重提 | 删 TC92+TB91 |
| zzcl 终止处理 | '23' | PRC_GENERATE_TFMX 退费重生成 | 清终止字段/ATB90R←'3' |
| dzdwcl 调转处理 | '24' | ATB90R←'2'/TB912←'2' | ATB90R←'3'+删 TB91 |
| dzjsdycl 结算单元调转 | '26' | TB912←'2' | update TC90 atb90r='3'+删TB91 |

⚠ **'25' 姓名身份证变更无处理弹窗**——点"处理"无反应（遗产 bug）

### 2.4 合同终止或解除申请

**页面路径**：人才派遣管理 → 员工管理 → 合同终止或解除申请

**界面上你能看到的按钮**：

| 按钮 | 可见性 | 功能 |
|---|---|---|
| 查询 | 可见 | 查已生效合同（atb90r='3'） |
| 清空条件 | 可见 | 重置查询条件 |
| **终止申请** | 可见 | 弹出终止信息填写窗口 |
| 清单后终止 | **隐藏** | 弹出'27'全流程（不可达） |
| 历史合同查看 | 可见 | ⛔ 目标 JSP 不存在（死键） |

**终止申请操作**：
1. 查询到要终止的员工 → 点击 **【终止申请】**
2. 弹出终止信息窗口，填写：
   - 终止原因（atc90n/atc90o）
   - 终止日期（atc90i）
   - 是否享受失业金（atc90l）
   - 工资/基数相关
3. 点击确认 → 系统按用工性质分流：
   - **劳务工**：直接调过程立即终止
   - **派遣工/保险代理**：走 TB91 审核流（'23'）→ 等待审核

**终止提交后系统自动处理**：
- TC90.ATB90R←'2'（送审）
- TC90.ATB910←TB91 新申请号
- TC90.AAE100←'0'（**提交未审即失效**——即使打回也不会自动恢复）
- TB91.ATB911←'23'（终止类型）
- 前端同时置 aaa204←aaa202 等报减年月镜像

⚠ **风险**：提交终止后员工主记录立即失效，如果打回需要人工恢复

### 2.5 员工信息变更申请

**页面路径**：人才派遣管理 → 员工管理 → 员工信息变更申请

**界面上你能看到的按钮**：

| 按钮 | 功能 |
|---|---|
| 查询 | 查已生效员工 |
| 重置 | 清空查询条件 |
| **基本信息变更(不审核)** | 弹窗直改 AC01（身份证/姓名除外） |
| **变更基本信息** | 弹窗改姓名/身份证（送审'25'） |
| **变更合同信息(审核)** | 弹窗改合同/参保信息（送审'21'） |

#### 基本信息变更(不审核) 操作：
1. 查到员工 → 点击 **【基本信息变更(不审核)】**
2. 弹窗中修改允许变更的字段（身份证/姓名只读）
3. 保存 → AC01 直接生效 + TC90 28 个字段同步更新
4. ⚠ 如果员工有多份合同，只有第一份 TC90 被更新（遗产 bug）

#### 变更基本信息(送审) 操作：
1. 查到员工 → 点击 **【变更基本信息】**
2. 弹窗显示变更前/后对照
3. 修改姓名或身份证号 → 系统调 PRC_PARSE_AAC002 校验
4. 保存 → **双次保存互链**：先落 TC92+TB91（atb910=0），回填后第二次互写 ATB91Z↔ATC920
5. 提交后等待 tdbd 审核（'25' 类型）
6. ⚠ 双保存互链脆弱：第二次失败 → 无主 TC92 或无关联 TB91

#### 变更合同信息(审核) 操作：
1. 查到员工 → 点击 **【变更合同信息(审核)】**
2. 弹窗显示几十组"变更前/变更后"对照字段（含缴费基数等）
3. 修改需要变更的字段的"变更后"值
4. 提交 → 生成 TC92+TB91（'21' 类型）→ 等待审核
5. ⚠ 未改动也可提交（系统不拦截）

## 第四章 派遣费用操作

### 4.1 派遣单位月费用结算

**操作入口**：人才派遣管理 → 派遣费用管理 → 派遣单位月费用结算

1. 选择结算单元和年月
2. 系统按合同汇总该月费用（服务费+社保+公积金+工资代发）
3. 生成费用清单（TC93 表）→ 可导出
4. 确认结算 → 费用锁定（当月不可再变更参保地）

### 4.2 导出应发工资名册

1. 选择结算单元和年月 → 查询当月应发工资汇总
2. 导出 Excel 名册

### 4.3 工资实发

1. 查询已生成的工资发放数据
2. 确认工资实际发放金额（与应发金额核对）
3. 确认后工资进入"已实发"状态

## 第五章 系统管理操作

### 5.1 代码信息维护

**操作入口**：综合信息管理 → 系统参数信息管理 → 代码信息维护

**界面上你能看到的按钮**：

| 按钮 | 功能 |
|---|---|
| 查询 | 按分类查询代码 |
| **保存** | 保存新增/修改的代码项 |
| **删除** | 删除选中代码项 |

**操作**：新增分类代码 ≤ 10 字符（如 'ZZZ'），填写码值和含义 → 保存 → 立即生效

### 5.2 行政区划维护

1. 树形结构显示行政区划（省→市→区→街道）
2. 新增/修改/删除行政区划
3. 区划代码用于参保地选择、区划筛选

### 5.3 综合参数信息维护

1. 维护系统级参数（AA01 表）
2. 每个参数有：业务线代码、参数代码、参数名、参数值
3. 生产仅 9 行——此功能极少使用

### 5.4 社保参数维护

维护公积金比例表（AA94），按险种和参保地设置缴费比例

### 5.5 社保报减异动期设置

设置每月异动日（如 18 号），影响报增年月计算逻辑：
- 当前日期 ≤ 异动日 → 当月报增
- 当前日期 > 异动日 → 下月报增

## 第六章 按业务场景速查

### 场景一：新单位签约全流程

```
第一步：基本信息管理 → 单位基本信息维护 → 录入单位信息 → 保存
第二步：人才派遣管理 → 单位协议管理 → 新签单位协议申请 → 填写协议 → 暂存 → 提交
第三步：人才派遣管理 → 单位协议管理 → 协议信息审核 → 审核通过
第四步：人才派遣管理 → 参数管理 → 险金户信息维护 → 确认户头已设置
```

### 场景二：新员工入职（从登记到社保生效）

```
第一步：员工管理 → 新增员工信息申请
  ├─ 填写基本信息 → 【暂存】 → 状态='1'
  ├─ 确认无误 → 【提交到审核】 → 状态='2'
第二步：员工管理 → 员工信息审核
  ├─ 勾选员工 → 【批量审核通过】 → 状态='3'（生效）
第三步：员工异动 → 员工社保报增申请
  ├─ 选择户头+区划 → 查询 → 确认 → 【报增】
第四步：员工异动 → 社保异动报盘回盘
  ├─ 生成报盘文件 → 提交社保局
  ├─ 导入回盘结果 → ATC9W8→'4'（当月锁定）
```

### 场景三：员工离职

```
第一步：员工管理 → 合同终止或解除申请
  ├─ 查到员工 → 【终止申请】 → 填写终止信息 → 提交
  ├─ 员工状态 → ATB90R='2' + AAE100='0'(即时失效)
第二步：员工管理 → 员工信息审核
  ├─ 勾选终止员工 → 【批量审核通过】 → ATB90R='5'(已终止)
第三步：员工管理 → 审核信息处理
  ├─ 处理退费/经济补偿金等后续事务
```

### 场景四：员工信息变更

```
手机号变了：
  员工管理 → 员工信息变更申请 → 查到员工
  → 【基本信息变更(不审核)】 → 修改手机号 → 保存 → 立即生效

改名了：
  员工管理 → 员工信息变更申请 → 查到员工
  → 【变更基本信息】 → 输入新姓名 → 保存 → 生成'25'审核单
  → 等审核 → 通过后系统自动同步 4 表

缴费基数变了：
  员工管理 → 员工信息变更申请 → 查到员工
  → 【变更合同信息(审核)】 → 修改基数 → 保存 → 生成'21'审核单
  → 等审核 → 通过后 TC92 `_后`列刷入 TC90
```

### 场景五：月度社保经办

```
每月月初：
□ 参数管理 → 社保报减异动期设置 → 确认本月异动日
□ 员工异动 → 员工社保报增申请 → 生成本月新增报增
□ 员工异动 → 员工社保报减申请 → 生成本月离职报减
□ 员工异动 → 社保异动报盘回盘 → 生成报盘文件→提交社保局
□ 员工异动 → 社保异动报盘回盘 → 导入回盘结果→确认
□ 每年 3-7 月：基数确认（各险种）
```

### 场景六：月度工资操作

```
每月：
□ 派遣费用 → 导入工资信息维护 → Excel 导入当月工资
□ 派遣费用 → 导入工资信息审核 → 审核工资数据
□ 派遣费用 → 派遣单位月费用结算 → 月度结算
```
