## 第十章 派遣费用管理（月度费用全流程）

### 派遣费用管理的业务含义

派遣公司每月需要为每个用工单位的派遣员工计算工资、缴纳五险一金、向单位收取费用。
本章覆盖从"导入工资"到"费用结算"的月度全流程。

### 操作时序（按月循环）

```
每月月初：
① 导入工资信息（Excel 上传） → ② 工资审核 → ③ 费用结算 → ④ 工资发放
      ↓                                    ↓
⑤ 社保报盘/回盘                    ⑥ 发票开具/到账确认
```

---

### 10.1 导入工资信息（Excel 导入）

**操作入口**：派遣费用管理 → 导入工资信息维护

1. 下载工资导入模板（Excel）
2. 模板列：员工姓名、身份证号、合同终止日期、费用结束年月、
   社保/公积金/医保/工伤报减年月、合同终止原因、是否享受失业金、
   各险种参保状态等（16 列）
3. 填写完毕后上传
4. 系统自动解析 → 数据写入暂存表 → 显示导入结果（成功/失败行数）
5. 首次上传返回**批次号**（后续审核和提交按批次号操作）

**操作入口**：派遣费用管理 → 导入工资信息审核

1. 选择批次号 → 查看导入数据明细
2. 合格数据（ace10a='3'）和不合格数据（ace10a='2'）分别显示
3. 审核合格数据 → 点击提交 → 数据正式入库（TC90 表）
4. 提交过程按"部门+结算单元"分组落库

⚠ **注意**：
- 该导入线当前因包编译失败（PKG_IMP）不可用
- 只有"合同终止&信息更新"导入线（tc90_impdel）走的是更新逻辑，其余为新签导入

### 10.2 工资项目细项设置

**操作入口**：派遣费用管理 → 工资项目细项设置

1. 选择用工单位 → 系统显示该单位合同下的工资项目列表
2. 每个项目有：排序号、项目名称、标准金额、数量
3. 点击修改 → 系统执行"**换行式修改**"（删旧行+插新行，PK 变化）
4. 白名单字段（12 个）：合同ID/排序号/项目名/经办人组/结算单元/标准/数量/标志

**换行式修改**是本页面的核心机制——修改不是原地更新而是删除旧行+插入新行。

### 10.3 派遣单位月费用结算

**操作入口**：派遣费用管理 → 派遣单位月费用结算

1. 选择结算单元和年月
2. 系统按合同汇总该月应收费用（服务费+社保+公积金+工资代发）
3. 生成费用清单（TC93 表）→ 可导出
4. 确认结算 → 费用锁定

⚠ 结算后当月数据不可再变更参保地（过程检查 TC93 有当月行则拒绝）

### 10.4 其他费用功能

| 功能 | 操作 | 说明 |
|---|---|---|
| **导出应发工资名册** | 选择年月→导出 Excel | 生成当月应发工资汇总 |
| **经济补偿金录入** | 录入补偿金金额→确认 | 经济补偿金 = N 个月工资（按劳动法计算） |
| **派遣费用预估** | 选择单位→预估下月费用 | 用于单位预算参考 |

| **工资实发** | 确认工资实际发放金额 | 与应发金额核对 |
| **个人补退导入** | Excel 导入个人补退数据 | 少补多退 |
| **险金计算器** | 输入基数→自动计算五险一金 | 前台快速估算工具 |

## 第十一章 资金管理（发票/到账/垫付）

### 11.1 发票管理

**业务含义**：派遣公司每月向用工单位开具服务费发票

**开票流程**：
1. 菜单 → 资金管理 → **发票申请（单位）**
2. 选择单位 + 填写发票金额 → 提交申请
3. 菜单 → 资金管理 → **发票管理** → 管理员审批
4. 审批通过后开具发票

⚠ 当前因包编译失败（PKG_财务）发票导入不可用

### 11.2 到账确认

**业务含义**：用工单位将费用汇入派遣公司账户后，在系统中确认到账

| 页面 | 操作 | 说明 |
|---|---|---|
| 到账（单位） | 确认单位汇款到账 | 录入到账金额/日期 |
| 到账（个人） | 确认个人缴费到账 | 个人承担部分 |
| 到账（个人转账确认） | 确认个人转账到账 | 转账方式到账确认 |

### 11.3 垫付管理

**业务含义**：员工离职当月单位未及时付款，派遣公司先行垫付社保费用

| 步骤 | 页面 | 操作 |
|---|---|---|
| 1 | 垫付申请 | 发起垫付申请（选择员工+金额） |
| 2 | 垫付审核 | 财务审批垫付申请 |
| 3 | （后续核销） | 单位欠费核销/个人欠费核销 |

### 11.4 工资可发确认

**业务含义**：财务确认本月工资可以发放（社保已扣、费用已到账）

1. 菜单 → 资金管理 → **工资可发确认**
2. 选择结算单元和年月 → 查看可发金额
3. 确认后工资进入"可发放"状态 → 下游工资发放页面执行

### 12.2 基数确认操作（每年一次，通常 3-7 月）

**业务含义**：每年社保局发布新的缴费基数上下限，需要对所有在职员工进行基数调整确认

**操作流程（以社保为例）**：
1. 菜单 → **员工异动/补退费管理** → **工资基数确认(社保)**
2. 选择结算单元和年月 → 查询需确认的员工列表
3. 系统按新基数上下限自动调整：
   - 低于下限 → 按下限缴纳
   - 高于上限 → 按上限缴纳
   - 在范围内 → 按实际工资缴纳
4. 核对无误 → 点击确认
5. 确认后生成基数调整明细 → 报盘提交给社保局

**各险种基数确认入口对照**：
| 险种 | 页面 | 过程 |
|---|---|---|
| 社保 | 工资基数确认(社保) | PRC_社保缴费基数确认 |
| 医保 | 工资基数确认(医保) | PRC_医保缴费基数确认 |
| 公积金 | 工资基数确认(公积金) | PRC_公积金缴费基数确认 |
| 工伤 | 工资基数确认(工伤) | PRC_工伤缴费基数确认 |
| 公积金上下限调整 | 公积金基数上下限调整 | PRC_公积金基数上下限调整 |

⚠ 公积金基数上下限调整有独立的审核页面（公积金基数上下限调整审核）

### 12.3 工资基数调整

> 适用场景：员工工资变化导致缴费基数需要调整

1. 菜单 → **员工异动/补退费管理** → **工资基数调整**
2. 查询员工 → 修改缴费基数
3. 系统校验新基数是否在上下限范围内
4. 提交后生成基数调整记录

### 13.3 险金户头维护

**业务含义**：每个参保单位有一个或多个"险金户头"（AA03 表），报增/报减/回盘都以户头为单位操作

1. 菜单 → 参数管理 → **险金户信息维护**
2. 全库仅 4 行（核心主数据）
3. 每行有：户头编号、户头名称、社保账号、公积金账号
4. 新增户头 → 即可用于所有报增/确认过程（无格式限制）
5. ⚠ 户头数据是参保流程的前置主数据——新增后立即可用

## 第十四章 月度社保经办标准流程（详细版）

### 第 1 步：检查异动期设置

- 菜单 → 参数管理 → 社保报减异动期设置
- 确认本月异动日（如 18 号）
- 异动日之前的增减 → 当月生效；之后的 → 下月生效

### 第 2 步：社保报增

- 员工异动 → 员工社保报增申请
- 选择险金户头 → 选择区划
- 系统列出当月应报增人员（新入职且费用开始月=当月）
- 逐人确认 → 过程生成报增明细
- 如果报增过程返回错误 → 检查：
  - 户头是否存在（AA03）
  - 经办人是否存在（SYS_ORG_USER_UNIT）
  - 当月是否已回盘（ATC9W8='4' 存在则拒绝）

### 第 3 步：社保报减

- 员工异动 → 员工社保报减申请
- 查询本月离职员工 → 生成报减行
- 通过保存通道写入（非过程）

### 第 4 步：报盘

- 员工异动 → 社保异动报盘回盘
- 选择户头和年月 → 生成报盘文件 → 提交社保局

### 第 5 步：回盘

- 社保局处理后返回结果文件
- 导入回盘文件 → 系统更新员工社保状态
- **回盘后 ATC9W8 置'4'（已回盘）** → 当月锁定

### 第 6 步：月转款查询

- 员工异动 → 社保月转款情况
- 查看本月社保费用转款明细 → 与银行流水核对

## 第十六章 新员工入职到离职的完整月度操作年历

### 入职月
```
□ 前台：新增员工信息申请 → 暂存 → 提交到审核
□ 审核：员工信息审核 → 审核通过
□ 社保：员工社保报增申请 → 选择户头 → 报增
□ 社保：社保异动报盘回盘 → 报盘 → 回盘确认
□ 医保：员工市医保报增申请 → 报增（如参加市医保）
□ 工资：工资项目细项设置 → 设置工资项目
□ 工资：导入工资信息维护 → 导入首月工资
□ 工资：导入工资信息审核 → 审核通过
□ 财务：派遣单位月费用结算 → 月度结算
```

### 在职每月
```
□ 工资：导入当月工资 → 审核
□ 财务：工资可发确认 → 确认可发
□ 财务：工资发放 → 发放
□ 财务：到账（单位） → 确认单位费用到账
□ 财务：发票申请（单位） → 开具服务费发票
□ 每年 3-7 月：基数确认（各险种）
```

### 离职月
```
□ 前台：合同终止或解除申请 → 发起终止 → 提交
□ 审核：员工信息审核 → 审核通过（ATB90R='5'）
□ 社保：员工社保报减申请 → 报减
□ 社保：社保异动报盘回盘 → 报盘回盘
□ 员工管理：审核信息处理 → 处理退费/终止事务
□ 员工管理：劳动合同终止员工查询 → 打印解除证明
```
