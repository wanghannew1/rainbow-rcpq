## 0. 本组公共模型（先读）

**协议状态机**（TB90）：`ATB90R` 1=暂存 / 2=提交审核 / 3=审核通过(生效) / 4=审核不通过(打回) / 5=终/中止(失效)；`ATB90P` 1=正常 / **0=冻结**（续签、终/中止流程中）；`AAE100` 1=有效 0=无效。协议编号 `ATB903`=`yyyyMM||lpad(max(substr(atb903,7))+1,4,'0')`（tdaa_cont.js:138、tdab_dialog_xq.js:378，**max+1 无锁，并发可重号**）。

**审核链**（TB91）：`ATB911` 审核类型——11=新签协议 / 12=续签协议 / 13=变更协议 / 14=终/中止协议（tdad_cont.js:59、tdae_cont.js:64；20~27 为员工合同审核，不属本组）；`ATB912` 1=暂存 / 2=待审 / 3=通过 / 4=打回；`ATB91Z`=关联业务主键（协议号）；`TB90.ATB910` 反挂审核单号。经办分两组：提交侧 AAE011/017/019/020/022/036，审核侧 BAE011/017/019/020/022/036。

**表**：TB90 协议 → TB93 结算单元（atb900 外键，另有 `atb900_1` 溯源列）→ TB92 变更申请（主键 atb920，变更后值字段带 `_` 后缀）→ TB91 审核（全组共用）。单位档案 AB01（树，id/parentid）+ AB06 单位变更日志 + AB07 联系人 + **AB01_CHILD 扁平索引表**；个人档案 AC01 + AC06 变更日志 + AC07 记录事项 + CC0P 登记流水。通用通道 `LemisBusinessMgrPoJo.query/update` 即 HQL 直查/直写，走 PoJoAction。
