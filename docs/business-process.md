# 彩虹人才管理系统 — 业务流程与数据全景

> 依据: 旧系统 414 页面/683 交互 + 生产库数据分布 + 新系统端到端验证(scripts/e2e_business.py, 20/20 通过)。
> 业务视角 = **劳务派遣公司运营 ERP**(吉林省彩虹人才开发咨询服务有限公司): 用工单位把岗位外包给派遣公司,
> 派遣公司招聘/签约/发工资/缴社保/开发票, 按结算单元与单位结算服务费。

## 一、业务全景

```
用工单位(909 家: 吉大二院/长春中医药大学附属医院/博众汽车…)
   │ ①新签单位派遣协议(td/a/a, TB90 921 + AB07)
   ▼
结算单元 TB93(1304 个: 单位×费用类别×结算方式 的最小核算单元)
   │ ②派遣员工登记(tdba 页录 + tdbp 四 Excel 弹窗, TC90 52268 份合同)
   ▼
劳动合同 TC90 ──审核(TB91, 10 万+流水: 20新签/21变更/23终止)──► 生效(atb90r='3', 17673 份在岗)
   │ ③五险一金报增(td/c): 名册(TC9W社保/TC9W1医保/TC9U公积金)→Excel导入核对→社保经办回盘→确认
   ▼
月度循环(每月):
   ├ ④工资: 模板(tdda/tddf)→Excel导入(tddc 通道, TC93 118.9 万行)→核对(tddg 三金额比对)
   │        →确认(atc93p='0')→险金计算(PRC_计算险金→TC01)→社保月数据(AC10 21946)
   ├ ⑤征缴: TJ0A1-F1 六表(74.7 万行)与社保经办对账, 补缴/退缴明细(TC9W_BP01/04)
   ├ ⑥收款: 银行到账导入(TB97 32370, 工行/建行/吉林银行)→核销(已核销金额/结余)
   └ ⑦开票: 发票导入(TB99 5895, 8 类费项目: 服务费/工资/保险费/考试费/外包…)
   │ ⑧变更与终止(td/b/d-e 状态机): 续签(TC90_QDLS)/调转(TC92 10218)/终止(报减名册)
   ▼
专项业务: 生育补贴(TC04 973)/意外险(TC05 16950)/特殊情况(TC06 133)/经济补偿金(TD04)
```

## 二、业务员日常办理流程(按月份节拍)

### 每月月初 — 增员
1. **单位提报用工需求** → 业务员在 `td/a` 维护单位派遣协议(合同单价/服务费/结算方式)。
2. **新员工签约**: `tdb/a` 单人录入(派遣员工登记: 基本信息/合同/险金/退休三方/工资账号)。
   批量: `tdb/p` 四个 Excel 弹窗(新签/终止/更新/续签 + 新增保险), 文件经通用导入引擎
   (`sys_import` 配置驱动)落批次表 TC90_BP 等, 每批生成批次号(SEQ_CE10_ACE100)与 CE10 批次记录。
3. **批量校验**: 弹窗"校验"调 `PKG_派遣批量导入.PRC_员工导入校验` — 逐行身份证解析(AAC002
   15→18 位升级/校验位)、代码项比对(AA10)、有无有效合同冲突、养老/医保/公积金基数上下限
   (AA98, 经 PKG_COMMON/limit 函数)、退休/超龄、费用开始年月时限(AA95)…结果写回批次行
   ace10a(3 过/2 拒+原因), 汇总提示"共导入 N 条, 符合 X 不符合 Y"。
4. **提交**: `PRC_员工导入提交` — 新人生成 AC01(基本信息, 身份证解析性别/生日)+TC90(合同
   全字段+派遺编号 ZYNUM)+TC90_LIST(历史镜像)+TB91(审核流水, 类型 20/标志 2 待审);
   变更单走"变更单位"四险种状态机(参保继承/基数调整/报减旧合同)。

### 每月初 — 审核岗(双人复核)
5. `tdb/f` 审核查询(待审: TB912='2')→ 通过 = 行状态改 atb90r='3'/TB912='3' 提交
   (`tdbf_tdbfService.doXinqCommit`, 行编辑保存模型); 不通过 = `doXinqCancle`(删 TC90+TB91)。
6. 特殊回退: `terminateCancel/reCommit/doRenewCancle/doJsdyCancle`(终止/续签/结算对应撤销)。

### 每月中 — 五险一金
7. **报增名册生成** → 单位上网维护信息 → 业务员 Excel 导入核对(`PKG_IMP.CHECK_TC9W_IMP`,
   身份证/性别/招录用时间/月工资/新增原因/用工性质/户口/邮编… 逐项校验), 提交回写 TC9W。
8. **社保经办回盘**(每月): 回盘文件导入 → `TC9W_BP01`(社保)/`BP04`(医保)比对确认 → 大额医疗
   承担方按 aaa803 判定 → 审核确认(atc9w8='3' 后该月冻结, 不能再办特殊登记)。
9. **公积金**(TC9U)/医保(TC9W1)同构; 医保分省(99)/市(非 99)两套参数(AA94 费率表)。

### 每月固定日 — 工资与险金
10. **工资编制**: 按工资模板生成 TC93 行(每单位×每员工×发放次第); 业务员从单位收工资 Excel
    → `td/d/c` 导入(/import/tddc): 12 类金额列按 AA90 工资项类别累加进 TC93 金额列+明细串。
11. **工资核对**: `td/d/g` 导入核对批次(TC93_BP1) → `PKG_IMP.CHECK_TC93`: 找同键 TC93, 比对
    本次工资总额/年终奖/经济补偿金三金额 + 年终奖年度一次发放检查; 提交 `COMMIT_TC93`:
    最低工资 80% 门槛(AA99, atc93l=0 时总额<80% 拒) → `PRC_SALARYCOMPUTE_SH`(生产已空壳化)
    → atc93p='0' 确认。
12. **险金计算**: `PRC_计算险金`(TC90+AA97 基数+AA94 费率+征缴 TJ0 覆盖) → TC01 结果 →
    生成 AC10 社保月数据(机器补 atc9en='3')。视 TC90_XJ 等一览视图即此链路的查询面。

### 每月末 — 收款开票
13. **到账核销**: 出纳拿银行回单 Excel → `td/l/y` 三银行导入(TB97_BP→TB97), 生成到账记录
    (金额/对方户名/日期), 之后在 `td/l` 逐笔核销到结算单元。
14. **开票**: `td/l/b` 发票导入(TB99_BP→TB99), 8 类费项目金额合计生成 atb993 项目编码串。

### 变更与退出(随时)
15. **续签**: `tdb/p` 弹窗(批次 TC90_BP3) → 匹配生效合同 → 写签订历史 TC90_QDLS + atc90f='2'。
16. **调转**: `td/b/d` 变更审计(TC92 全字段前后镜像 10218 条)。
17. **终止**: `tdb/b` 弹窗(TC90_BP1: 终止日期/四险报减年月/终止原因/失业金/经济赔偿) →
    匹配合同 → `PRC_员工终止导入提交`(有效合同走审核 TB911=23, 已终审的直接落账) →
    报减名册 → 工资结束年月(atc90av)/费用结束年月(aae003)。

### 专项(按需)
- **生育补贴**(td/c/bf, TC04): 按医保编号匹配合同+费款所属期查重。
- **意外险**(td/c/bi, TC05): 结算单元名称+保单号(TB9B)匹配, 已结算月份拒绝。
- **特殊情况**(td/c/aw, TC06): 六险种异动情况登记, 社保/医保/公积金月确认后冻结。
- **经济补偿金**(td/d/x, TD04): 近 12 个月收入×补偿月数, F_PARSE_MONEY 生成中文大写。
- **工伤/工亡**(td/i), **退休申报**, **提醒事项**(td/n)。
