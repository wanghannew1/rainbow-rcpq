## 0. 静态资源 parity 铁律（东软战役 59 卷, 2026-11-26）

encode.js+.rdx 模板）是运行时必需**——页面 JS 弹窗 url 直写 `/pages/...`、common.js:3022
引用 `/report/encode.js`、报表引擎读 `/report/**.rdx`。卷57 纯源码部署曾因缺这两棵树导致
