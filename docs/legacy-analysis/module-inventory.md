## 4. 规模总账

- **需重写业务面**：约 12 个模块、375 页、686 交互、其中自定义交互 66 个（xa 3 + az 9 + td/a 3 + td/b 25 + td/c 23 + td/d 6 — wts 的 3 个除外）
- **零代码模块**：114 页/185 交互（td/g+td/h+td/i+td/l+td/n）——成本集中在**元数据迁移**（约 135 个 datastore）而非代码
- **Java 总量**：约 5,800 行业务 Service（xa 642 + az 1,215 + td 3,962）
- **过程依赖**：td/b 18 + td/c 11 + td/d 8 + td/a 2 + td/n 1 ≈ 40 处调用点，涉及约 20 个 PL/SQL 过程——逐包评审清单见 database-migration-inventory.md §3

## 5. 与 ADR 的关系

- 原 ADR「模块顺序 xa→td/i→td/b→td/c+d」中的 **td/i 调整为波次 9**（纯通用零成本，无需早做）；
- **az 提前到波次 2**（主档依赖）；td/g 提前到波次 3（通用化验收）；其余一致。
